# Open Ships Homebrew Tap

Homebrew packages for [Open Ships](https://github.com/open-ships) developer
tools.

## n2k

Install the NMEA 2000 command-line tools:

```bash
brew install --cask open-ships/tap/n2k
```

Upgrade:

```bash
brew upgrade --cask open-ships/tap/n2k
```

The cask is generated by
[`open-ships/n2k-cli`](https://github.com/open-ships/n2k-cli) and synchronized
from each published GitHub release.
